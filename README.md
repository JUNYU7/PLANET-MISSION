# PlanetMission · 火星巡视器仿真平台

基于 NASA HiRISE 真实火星地形数据，自动生成可在 Gazebo 中运行的火星巡视器仿真场景，并提供具身导航任务的实时推演与评测。

## 这是什么

行星巡视任务的地面验证长期依赖实物样机与物理试验台，周期长、成本高，且难以复现「细小障碍导致车轮反复空转」这类只在特定地形耦合下才出现的失效模式。本平台用米级真实高程数据替代示意性地形，把「换源 — 判读 — 规划 — 推演 — 导出」整条链路打通，使轮地接触关系与坡度阈值具备工程参考价值。

## 主要特性

**真实地形驱动**。高程与正射影像全部来自 NASA/USGS 公开行星遥感产品，不使用示意性地形。区域配置与源数据解耦，新增一个行星区域只需增加一条配置，无需修改算法代码。

**全链路量纲自洽**。投影参数从栅格自身的坐标参考系实测读取，像元尺寸按栅格实测值而非标称值，车体尺度按真实巡视器标定。任一环节均可核查来源，杜绝凭经验填写参数引入的系统偏差。

**物理自洽的障碍判据**。以局部隆起作为第二判据区分巨石与可碾碎碎石，把是否阻挡从语义分类的粗放判断细化为可解释的几何判据——实测约八成巨石单元的隆起量不足半米，仅按类别判断会让车轮在原地反复空转。

**三类任务实时推演**。穿越、抵近、勘测三类任务以逐帧流式方式推送前端，车辆状态、地形判读与遥测数据在同一时间轴上更新。

**Gazebo 场景导出**。任一区域可导出为独立运行的 ROS2 功能包，含地形网格、纹理、世界文件与启动脚本，导入目标仿真环境后无需本平台即可运行。

## 快速开始

### 1. 安装后端

```bash
cd backend
pip install -r requirements.txt
python start.py
```

服务默认监听本地端口，启动时会报告各区域的生成统计与索引更新结果。

### 2. 安装前端

```bash
cd frontend
npm install
npm run dev
```

浏览器访问提示的地址即可进入火星全球视图。

### 3. 准备数据

**仓库不包含任何行星遥感数据**（合计约 9.5 GB，且许可条款要求从发布方获取）。首次运行前需自行下载并放入 `data/` 目录：

| 文件 | 用途 | 分辨率 |
|---|---|---|
| `JEZ_hirise_soc_006_orthoMosaic_25cm_Eqc_latTs0_lon0_first.tif` | Jezero 正射影像 | 0.25 m/px |
| `JEZ_hirise_soc_006_DTM_MOLAtopography_DeltaGeoid_1m_Eqc_latTs0_lon0_blend40.tif` | Jezero 高程 | 1 m/px |
| `DTEEC_010414_1900_010269_1900_A01.img` | Athabasca 高程（ISIS/PDS 格式） | 1 m/px |
| `PSP_010414_1900_RED_A_01_ORTHO.jp2` | Athabasca 正射影像 | 0.25 m/px |
| `Mars.tif` | 全球影像贴图 | — |

数据来源：Mars 2020 TRN HiRISE DTM Mosaic (SOC 006) 与 MRO HiRISE 单景立体测绘产品。前两者从行星数据系统影像目录获取，单景产品由亚利桑那大学 HiRISE 操作中心生成。具体许可见 `backend/app/settings.py` 中各区域的 `credit` 字段。

若 `data/` 为空，服务会在启动阶段明确报告缺失的文件名与查找过的目录，而不是在切换区域时才失败。

## 三类任务

**穿越**（TRAVERSE）。在地形上逐个点击放置途经点，数量不限，相邻点自动连线并随地形起伏。新点追加到最近一个尚未完成的穿越活动中，无未完成活动则新建。

**勘测**（SURVEY_PATH）。放置三个不共线的顶点，系统在满三点时自动补入质心并结束放置。仿真中火星车从质心出发依次驶向三个顶点，每到达一个先完成坡度与光照检查，再驱动相机朝质心方向拍一张照片，共三张。由于拍照是离散决策，动作空间在速度与角速度之外追加了成像通道。

**抵近**（TARGETED_APPROACH）。单击放置目标点，朝向由系统根据来向自动推导，无需手动指定。到位后先原地起旋使车体转向期望朝向，再驱动雷达斜向下扫视半径十米的地形。

## 常见问题

**场景地形异常平坦。** 先用生成阶段输出的坡度中位数与相对起伏确认当前区域起伏，再对照数据源说明判断是否需要换源。中心点应使用 `backend/app/tools/` 下的扫描工具在满足缺失率门限的前提下选取起伏最大的位置，而不是直接取数据源中心。

**车辆在碎石区反复空转。** 若障碍单元语义类别为巨石但局部隆起很小，说明该障碍实为可碾碎碎石。确认障碍判据已启用局部隆起作为第二判据，且阈值与当前数据源的垂直精度匹配——不同数据源的垂直精度差异可达数米，阈值需相应重新标定。

**三维场景出现明显暗区。** 全球视图采用半球光打底加跟随相机的弱方向光塑形，任意朝向的面都有照度。若仍见暗区，检查是否被替换为单一方向光且目标设在场景原点——那会导致只有半个球面被照亮。
